# bigbang-ts

GPU-accelerated Three.js/WebGL playback of cosmic history on a logarithmic time axis, from the Planck epoch to the present day.

## Run locally

```bash
npm install
npm run verify
```

Open `index.html` through a static server after building. The portfolio shell serves the standalone view at `/bigbang-ts/` and embeds it on `/projects/bigbang-ts`.

Controls are keyboard- and pointer-driven: pause or resume playback, restart the timeline, adjust speed, orbit the camera, and zoom the scene.
