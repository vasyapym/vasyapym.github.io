lesson 013

what a token actually is

01

a model never sees words. text is chopped into tokens — frequent chunks of characters, learned from data.

02

each token maps to a number. "the" might be 262. the model works only on these integers.

03

rare words split apart: "tokenfold" becomes token + fold. this is why models miscount letters.

04

everything downstream — cost, context length, speed — is measured in tokens, not words.
