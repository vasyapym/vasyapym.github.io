01 / Start with pieces.

A tokenizer maps text into a sequence of token IDs. Depending on the tokenizer, a token may represent a word, part of a word, punctuation, whitespace, or another byte sequence.

Theredbook

Toy pieces only—not the output of a particular model tokenizer.

An embedding lookup maps each ID to a vector. The ID is a discrete label; the vector is a learned numerical representation. Later layers transform these vectors using surrounding context.

02 / Add order.

“The book is red” and “Red is the book” contain similar pieces in different arrangements. Attention needs access to positional information to distinguish such arrangements appropriately.

Transformer families introduce position in different ways: some add positional vectors to embeddings; others alter attention computations. The original transformer uses sinusoidal positional encodings.

03 / Form a weighted mixture.

Within an attention head, learned linear projections produce queries, keys, and values. Query–key comparisons produce scores. After scaling and any required masking, softmax converts those scores into weights.

scores = QKᵀ / √dₖ
weights = softmax(scores + mask)
output = weights · V

For each query position, the output is a weighted combination of value vectors. Multiple heads perform related operations in different learned projection spaces.

In causal self-attention, future positions are masked out. A position can mix information from allowed earlier positions and itself, not from future tokens.

Margin notes

dₖ
The key-vector dimension used to scale the dot products.

Softmax
Turns real-valued scores into nonnegative weights that sum to one.

Caution
Attention weights are not automatically a faithful explanation of a model’s answer.
