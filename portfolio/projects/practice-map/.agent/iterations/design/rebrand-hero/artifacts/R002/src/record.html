Editorial summary

The paper introduces a sequence-to-sequence architecture built around attention rather than recurrence or convolution. Its original system has an encoder and a decoder, each composed of repeated attention and feed-forward blocks.

Multi-head attention mixes information through several learned projections. Positional encodings provide information about sequence order. These components make more of the training computation parallel than a recurrent architecture permits.

Core distinction: attention is a learned information-mixing operation. It is not, by itself, a claim about understanding, truth, or consciousness.

What to notice

Queries, keys, values. Similarity scores between queries and keys become weights over value vectors. Track the matrix shapes before trying to interpret individual numbers.

Masking. The decoder’s self-attention prevents a position from attending to future positions during autoregressive training.

Architecture versus family. This paper’s transformer is encoder–decoder. Many later language models use decoder-only variants; “transformer” does not always mean this exact arrangement.

A useful reading question

Which parts of the system mix information across positions, and which parts transform each position independently?
