tokenfold / glossary

words, weighed

weight
a learned number. billions of them, adjusted slightly, become behaviour.
context window
the model's working memory, measured in tokens. outside it, nothing exists.
temperature
a dial on randomness. low: predictable. high: adventurous, sometimes nonsense.
hallucination
a confident output untethered from fact. fluency is not truth.
embedding
meaning as coordinates. nearby points, nearby ideas.
fine-tuning
teaching an already-trained model new manners with a smaller dataset.
