Archive / chronological index / 2017–2022

Not one invention.
A sequence of shifts.

A partial chronology of this collection. Publication order is not a ranking, and a milestone is not the whole field.

Return to ledger →
  1. 2017
    001 / Architecture

    Attention becomes the organizing principle.

    The transformer replaces recurrence in its sequence-to-sequence design with attention-based blocks. Position still needs an explicit signal.

    Attention Is All You Need / open dossier →
  2. 2018
    002 / Representation

    Read with context on both sides.

    BERT uses masked-token pretraining to develop bidirectional representations, then adapts them to downstream tasks.

    BERT / primary source ↗
  3. 2020
    003 / Scale

    Examples move into the context.

    GPT-3 studies few-shot task performance using examples supplied in the prompt, without task-specific gradient updates in that setup.

    Few-Shot Learners ↗
    004 / Retrieval

    The model consults a collection.

    RAG combines retrieval with generation for knowledge-intensive tasks. Retrieved material adds evidence; it does not guarantee correctness.

    Retrieval-Augmented Generation ↗
  4. 2021
    005 / Adaptation

    Update fewer parameters.

    LoRA represents adaptation updates through low-rank matrices while keeping the pretrained weights frozen, reducing the number of trainable parameters.

    LoRA / primary source ↗
  5. 2022
    006 / Alignment

    Preferences shape the response.

    InstructGPT combines supervised demonstrations and human-feedback-based training to improve instruction following. Helpfulness and factual reliability remain distinct concerns.

    InstructGPT / primary source ↗
