# The Dot
A page has a clock on it, and the clock is a class six lines long: one field, seconds, starting at zero, and one method, tick, whose entire body is this.seconds += 1. The page makes one with new Clock() and asks the browser to tick it once a second:

setInterval(clock.tick, 1000);

An hour later the page says 0. Nothing was thrown; the console is clean. But the window — the global object, which nobody asked — has acquired a property called seconds, and its value is NaN.

The line that would have worked is clock.tick(), and the place to slow down in it is the dot, because the dot does two things, and they concern two different objects.

The first is a search. clock is asked whether it has a property called tick, and it does not. new Clock() gave it one property of its own, seconds, and a link to a second object, Clock.prototype, which is where the class put the method. The dot follows the link and finds tick one step up. Had it not been there, the dot would have followed the next link, and the next, until one pointed at nothing.

The second is a decision, made as the call begins: for the length of this one call, this means clock. Not Clock.prototype, where the function was found — clock, where the search began, the thing on the left. clock.tick() does two things at the dot: it finds tick by asking clock and then the objects clock borrows from, and it decides that this means clock for this one call — which is why a method pulled off its object forgets who it belonged to.

setInterval(clock.tick, 1000) has the dot but not the call, and it does the first thing only. It searches, finds the function on Clock.prototype, and hands it to the timer — the function, and nothing else. A function is a value, and it carries no note saying which object it was found through: tick sits on Clock.prototype and is found by dots, on behalf of whichever clock stood to their left. There is one tick, and every clock there will ever be uses it.

A second later the timer calls the function it was given. There is no dot in that call — the timer was given a function and no object to go with it — and browsers, by specification, put the window on the left when they call a timer's function. So this is the window. this.seconds is undefined, undefined + 1 is NaN, and the window has a seconds count for the rest of the page's life. The clock's own seconds was never read or written, because the clock was never mentioned. It says 0 because it is 0.

The method did not forget which clock it belonged to. It never knew. Every other name in its body means what it meant where the body was written; this is the one that waits for the call.

Call it yourself with nothing on the left — const tick = clock.tick; and then tick() — and this is undefined. A class body is strict code, and strict code declines to invent a receiver, so undefined.seconds throws at once instead of counting on the window for an hour. In non-strict code the engine substitutes the global object, which is how a generation of detached methods wrote their fields onto the window without a sound.

The repair keeps the dot: setInterval(() => clock.tick(), 1000). The arrow is a function whose whole body is the dotted call, so the dot does both its jobs inside it, once a second. An arrow also has no this of its own — inside one, the word means whatever it meant in the surrounding code, settled where the arrow was written like any other name — which is why an arrow can be handed to a timer and lose nothing; it had nothing to lose. The older repair was clock.tick.bind(clock), a new function that always puts the clock on the left.

class was a reserved word for eighteen years before it did anything. In 2015 it was given a meaning, and the meaning is the arrangement above, written shorter: the class puts tick on Clock.prototype, one copy, where it had been put by hand all along, and the dot carries on as before. The arrangement itself — objects that borrow from other objects, a method found by walking up and run on behalf of whoever was asked, no class required — is from Self, a language designed at Xerox PARC in 1986 by taking the classes out of Smalltalk to see what was left. Self called the receiver self. JavaScript had to look like Java, and calls it this.
