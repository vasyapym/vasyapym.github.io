Variant lab — main-page project presentation

Five presentation variants for the six project cards, relay-generated. Minimal showcase, no polish: the six cards are fake static stand-ins (the real cards stay as-is in every variant). Judge the mechanics — layout, interaction, how much illustration shares the viewport.

V1 Focus folio V2 Text ledger V3 Inline dossiers V4 Scroll chapters V5 Archive drawer V6 Dossier stack V7 Marginalia V8 Spines

V1Focus folio

One generous stage, project counter, previous/next navigation. No neighboring previews. Illustration visibility: 1, primary.

V2Text ledger

Six typographic project rows dominate; the selected card occupies a narrower side inspector. Illustration visibility: 1, supporting. Relay's best default.

V3Inline dossiers

Six ruled headings. Opening one reveals its unchanged card and closes the previous dossier. Illustration visibility: 0–1.

V4Scroll chapters

Six text-only chapters drive one pinned card stage. Native scrolling, no scroll-jacking. Illustration visibility: 1, persistent.

V5Archive drawer

The section is entirely typographic. Selecting a project opens its card in a full-height modal drawer. Illustration visibility: 0, then 1. Strongest rejection of the "illustration collection" feel.

V6Dossier stack

Cards sit in a stack like folders in a drawer; only the top card renders. The rest are thin offset tab edges (number + title) peeking behind. Click a tab or use arrow keys to bring one forward. Illustration visibility: exactly 1; others are text tabs.

V7Marginalia

A long-form text with project names inline as superscript references. Clicking a reference opens the full card in a side sheet. Illustrations are fully demoted to supporting evidence: 0 on the page, 1 in the sheet on demand. Prose below is placeholder copy.

V8Spines

Six vertical "book spines" side by side, each 56px wide with rotated title text. Exactly one spine is open at a time and holds the card; the rest stay as hairline-bordered spines. Reads as a shelf, not a grid. Illustration visibility: 1.
