# Luna Lab

Личный репозиторий с проектами, экспериментами и инструментами для разработки.

Здесь я собираю небольшие самостоятельные проекты: каждый из них отвечает на свой вопрос, использует подходящие технологии и остаётся понятным для дальнейшего развития.

## Портфолио

В каталоге [`portfolio/`](./portfolio/) находится сайт с проектами.

Первый проект — **Линза текста** (`Text Lens`): локальный инструмент, который анализирует текст и показывает количество слов, символов, предложений, абзацев, примерное время чтения и самые частые слова.

## Запуск портфолио

Из корня репозитория установите зависимости и запустите React-сайт:

```bash
npm --prefix portfolio install
npm --prefix portfolio run dev
```

Откройте <http://localhost:5173> и выберите **Линза текста**.

Для работы анализатора запустите Go-сервис во втором терминале:

```bash
cd portfolio/projects/text-lens/service
go test ./...
go run .
```

Сервис работает на <http://localhost:8081>. React-сайт использует его endpoint `POST /analyze`. Быстрая проверка доступности: `curl http://localhost:8081/healthz`.

- проверка кода тестами и типами;
