# minimize-iteration2 — relay results log

Results log for the chat-model relay rounds (endpoint: the owner's chat
model, `comprehensive code -` opener). Kept minimal by rule (owner steer,
2026-09-25): each round records ONLY the prompt file reference, the outcome,
and the distilled practice that changes how the next brief is written. No
protocol scaffolding — hypotheses, pre-registered verdict rules, confounder
tables, verbatim A/B prompt pairs, round transcripts, and aborted
experiments are pruned (the S1–S5 register experiments were aborted or
closed by the owner with no scored data); git history keeps the originals.

## Practice (what moved the result)

- Brief shape that works: telegraphic prose-hybrid — task facts + verbatim
  base code + hard rails + explicit output contract ("exactly N numbered
  blocks ... nothing else").
- Rough-artifact contracts (draw the thing, skip fine details — polish and
  geometry repair are the integrator's job) beat prose-concept contracts
  for art asks.
- Task facts only: the relay never carries owner-evaluation or process
  details.
- Size details for the render, not the artboard: 0.7–0.8-unit hairlines die
  at the ~182px card render (S7: all five candidates rejected as too
  subtle).
- "Too subtle" and "too decorative" are the two fail modes bracketing the
  target (S7 vs S8/R019→R022): almost nothing added, and what remains
  clearly visible at render.
- When two independent models converge on one family, name that convergence
  as a trap in the next brief and require internal enumeration (8+
  vocabularies, kill/simulate/score before answering, work not shown) —
  the S9 deep-reasoning protocol, verdict pending.
- Fixed endpoint (the owner's chat model) can only produce descriptive
  findings — never H verdicts.
- Short wins (owner steer, 2026-09-25): the proven brief shape is ~60–150
  words of facts + rails + contract (S2 round 1: 5/5 usable, first try);
  the 900-word scaffold briefs are retired — template and exemplar recorded
  in brief-format.md, full history in S1-S5-full-history.md. Confirmed on
  S10 draw 2 ("ok result, not maximally good"): the prompt-28 facts-only
  shape is the starting format — begin there, vary one signal per round.
