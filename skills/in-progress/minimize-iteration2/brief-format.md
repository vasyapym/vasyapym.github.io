# brief format — current best hypothesis (revisable)

Claim (owner steer, 2026-09-25): short telegraphic briefs win. The proven
shape produced 5/5-usable draws with zero weak-route markers on the first
try (S2 round 1: "this worked great"; S5 rounds 2–4) while the long
scaffolding briefs (S1, pre-amendment arms) under-delivered or drew
nothing usable. Full verbatim history: `S1-S5-full-history.md`.

Confirmed on S10 (planck consistency, draw 2, prompt-28, ~190-word
facts-only): "ok result, not maximally good". Owner directive: **start
from this format** — the prompt-28 shape below is the default opening
brief; vary one signal per round from here and log what moved the
result.

## The shape

1. Opener, fixed: `comprehensive code - `
2. One telegraphic paragraph — the ask + task facts only: what the thing
   is, its current state (verbatim numbers), what's wanted, who owns the
   split ("exact split yours").
3. Hard rails, one line each: the banned set (explicit rejected siblings,
   not abstractions); the register steer when the owner stated one
   ("refined / detailed, not bold" — never write "one bold gesture": that
   clause produced the wrong register for this owner, S5 round 5); render
   size + legibility floor.
4. Output contract, explicit and final: "exactly N blocks ... nothing
   else", with the exact block format. Rough artifact: the model draws the
   thing; polish, exact colors, geometry repair are the integrator's job.
5. Never carry owner-evaluation or process details. Never add scaffolding
   (hypotheses, scoring rubrics, protocol steps) — that cargo is what the
   long briefs died of.

Size band that worked: ~60–150 words TOTAL for concept/mark asks, task
facts only, no verbatim base (S5 rounds 2–4). A 471-word telegraphic
brief with the verbatim svg + full house cargo drew "this doesn't seem
to work well" (S10 draw 1) — the same failure as S5 round 1: remaining
spec cargo drowns the creative ask. When the reply must match house
register, the integrator repairs carriers/colors afterward.
